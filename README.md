# Student Record Management System

A beginner-friendly Python CLI project for managing student records with CSV and JSON file storage.

## Features
- Add a student record
- View all records
- Update a record
- Delete a record (with confirmation)
- Search by student ID or name
- Save data in both `students.csv` and `students.json`
- Input validation and exception handling

## Requirements
- Python 3.8 or newer
- No external libraries required

## Run the project
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python student_manager.py
   ```

   On some systems, use `python3 student_manager.py`.

## Data files
The program creates `students.csv` and `students.json` in the same folder when you add or change records. Do not enter real or sensitive personal data when demonstrating the project.

## Concepts demonstrated
Functions, parameters, return values, loops, list/dictionary operations, file handling, CSV, JSON, validation, and `try`/`except` exception handling.
